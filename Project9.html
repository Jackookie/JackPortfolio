Project Overview

Burn the monster using light from your flashlight.

Features

  • Player control a character holding a Flashlight
  • Flashlight have spotlight
  • monster chase player
  • monster using ai navigation and navmesh
  • monster can get hurt by player flashlight
  • monster can die
  • monster have animation
  • Sound effects

Technologies Used

Unity 6, C#
