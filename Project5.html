Project Overview

A bucket try to catch coin as many as possible. Missed too much coin then its game over. A game based on company that I currently Working.

Features

  • Player Control Bucket in X axis(Left and Right)
  • Coin Spawner dropped from top
  • Control Movement with keyboard and Touchscreen
  • Mute Bgm and Sfx
  • menu Screen
  • Game Over Screen
  • Retry Function
  • Quit Function
  • Background Audio
  • Audio from dropped coin
  • Highscore System

Technologies Used

Unity 6, C#
