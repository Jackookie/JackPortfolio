Project Overview

Help the knight to defeat all the enemy and save the kingdom

Features

  • Player & enemy system with run, attack, hurt, and death animations
  • Health system for both player and enemies
  • Ground using a Rule Tile system
  • Background music for a more immersive vibe
  • Basic background visuals to set the scene
  • Handled collision logic after death to prevent further interactions
  • Connected GameObject layers with animation states (e.g. switching to a “Dead” layer during death animation)
  • Used animation events to trigger actions at specific points (like resizing collider during death)

Technologies Used

Unity 6, C#
